# Color Arcade

Небольшая цветная аркада на Python и Tkinter.

## Игры

- **Змейка** — собери 10 очков для победы.
- **Сапёр** — размеры поля 9x9, 16x16 и 30x16.
- **Три в ряд** — меняй соседние клетки мышью и набери нужное количество очков.
- **2048** — размеры поля 3x3, 4x4 и 5x5.

## Запуск

Требуется Python 3.12 или новее с установленным Tkinter.

```powershell
python main.py
```

Внешние Python-пакеты не требуются.

## Управление

- Стрелки или WASD — движение в змейке и 2048.
- Русская раскладка также поддерживается.
- Зажми левую кнопку мыши и проведи на соседнюю клетку в «Три в ряд».
- Левая кнопка мыши открывает клетку сапёра.
- Правая кнопка мыши ставит или убирает флаг в сапёре.
- `R`, `К` или `Р` — начать игру заново.
- `F11` — включить или выключить полноэкранный режим.
- `Esc` — выйти из полноэкранного режима.
- Кнопка «Тёмная тема» переключает оформление приложения.

## Файлы
